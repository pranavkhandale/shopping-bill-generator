# Shopping Bill Generator

A Python application to generate shopping bills and analyze expenses.

## Features
- Add multiple items with prices
- Calculate total bill
- Find highest priced item
- Find lowest priced item
- Item tracking and analysis
- Bill summary report

- ## How to Run
1. Clone this repo:
git clone https://github.com/pranavkhandale/shopping-bill-generator.git

2. Run the file:
python shopping_bill_generator.py
